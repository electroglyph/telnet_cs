All PRs should try their best to follow the C# best practices defined at csharp.md and AGENTS.md

Code comments should be detailed and accurate.

If your PR is a bugfix please provide the following:

If your PR is a feature, please include the following:

1. Comprehensive unit tests
2. Integration test if necessary
